# Airwise

A static weather and air quality dashboard.

## Publish with GitHub Pages

In the repository settings, open **Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then save. The site will be available at `https://yatish-as.github.io/airwise-weather/` after GitHub finishes its first build.

Weather, air quality, and geocoding data come from Open-Meteo. The map uses Google Maps JavaScript API. The AI and voice features use Puter.js and browser speech APIs.
